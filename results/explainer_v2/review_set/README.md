# First candidate review set

343 explained candidates deduplicate into 180 **repeat-pattern clusters** by consensus similarity (strand-canonical; substring or >=80% ungapped identity). A repeat-pattern cluster is a group of candidates whose consensus sequences resemble each other. It is NOT a biological family, system or classification: sequence similarity alone does not establish shared origin or function.

Selected for review: 15 interpretable `unclassified` representatives spanning 5 architectures, plus 8 high-scoring candidates with no sequence explanation.

**These are sequence-level descriptions only.** `unclassified` means the candidate span carries no overlapping annotation in the GenBank records used here. It is not a claim of novelty, function, or a new biological system, and nothing here should be read as one.

Alignment is ungapped: indel-containing arrays are under-reported.
