# First candidate review set

337 explained candidates deduplicate into 185 repeat families by consensus similarity (strand-canonical; substring or >=80% ungapped identity).

Selected for review: 11 interpretable `unclassified` representatives spanning 4 architectures, plus 8 high-scoring candidates with no sequence explanation.

**These are sequence-level descriptions only.** `unclassified` means the candidate span carries no overlapping annotation in the GenBank records used here. It is not a claim of novelty, function, or a new biological system, and nothing here should be read as one.

Alignment is ungapped: indel-containing arrays are under-reported.
